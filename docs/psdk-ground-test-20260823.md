# M400 PSDK 现场测试手册

这份文档只给测试人员看。程序启动后都从：

```text
主菜单 1 -> 飞控菜单
```

## 先做的事

在妙算上编译并启动：

```bash
cd ~/Payload-SDK/build
cmake --build . -j2
cd bin
./dji_sdk_demo_on_manifold3_cxx
```

安全要求：

- `j`、`m` 可以在地面测试。
- `k` 的 `S` 可以在地面测试。
- `n`、`p`、`t` 会让已经飞行的飞机运动，必须由飞手用 RC 先起飞并悬停。
- 程序不会自动起飞或降落，RC 必须始终可以接管。
- 任何异常、通信连续超时或飞机状态不确定时，立刻由飞手接管并停止测试。

## 通用按键

| 按键 | 作用 | 为什么按 |
|---|---|---|
| `M` | 获取 PSDK Joystick 控制权 | 让程序暂时发送控制指令 |
| `U` | 正常释放控制权给 RC | 测试结束，交回飞手 |
| `A` | 确认 `ABORTED` | RC 夺权后清除程序状态，回到 `IDLE` |
| `X` | 停止当前指令循环 | 手动停止发送，但不一定释放权限 |
| `Q` | 退出当前测试 | 通常必须先处于 `IDLE` |

## 1. `j`：只测权限，不让飞机运动

进入：`1 -> j`

正常获取和释放：

```text
M
U
Q
```

预期：

```text
PSDK authority confirmed; state=ACTIVE
Normal release confirmed; state=IDLE
```

测试 RC 夺权：重新进入 `j` 后输入 `M`，飞手切换 RC 模式或按 Pause。

预期：

```text
state=ABORTED
reason=RC_SWITCH_MODE(6)   # 或 RC_PAUSE(7) 等
```

然后按：`A -> Q`。

`j` 不调用起飞、降落、电机或运动 API，所以飞机不应移动。

## 2. `k`：基础四元组指令

进入：`1 -> k`

### 地面中性指令

```text
M
S
X
U
Q
```

`S` 每 50 ms 发送 `{0, 0, 0, 0}`，表示不要求前后、左右、升降或转向，不会主动起飞。

### 短时前进

飞手先用 RC 起飞并悬停，然后输入：

```text
M
F
```

程序最多 2 秒发送 `{0.2, 0, 0, 0}`，预期飞机低速向机头方向前进。飞手切换 RC 模式或按 Pause 后，程序应显示 `ABORTED` 并停止发送。

飞手接管并降落，再按：`A -> Q`。

## 3. `m`：地面读取飞控数据

进入：`1 -> m`。不需要起飞。

一次只按一个数字，等日志返回后再按下一个：

| 按键 | 读取内容 | 地面预期 |
|---|---|---|
| `1` | 飞行状态 | 返回状态数字 |
| `2` | 姿态四元数 | 返回 4 个姿态数值 |
| `3` | 高度融合 | 高度通常接近 0 |
| `4` | GPS 位置 | 返回经纬度/高度数据 |
| `Q` | 退出 | 结束订阅模块 |

每次读取后会取消该 topic。预期是成功返回并且不崩溃；任一 topic 崩溃或连续超时，立即按 `Q`，不要继续测试。

## 4. `n`：单轴真实运动

只有 `j/k` 正常后才做。飞手先用 RC 起飞并悬停，进入：`1 -> n -> M`。

一次只测一个方向：

| 按键 | 指令 | 预期动作 |
|---|---|---|
| `1` | `x=+0.2` | 向机头前进 |
| `2` | `x=-0.2` | 向后 |
| `3` | `y=-0.2` | 向左 |
| `4` | `y=+0.2` | 向右 |
| `5` | `z=+0.2` | 上升 |
| `6` | `z=-0.2` | 下降 |
| `7` | `yaw=-10` | 左转 |
| `8` | `yaw=+10` | 右转 |
| `X` | 停止 | 立即停止当前循环 |

每个动作最多 2 秒，结束后自动发送中性指令。测试中飞手可以切换 RC 模式夺权；预期程序进入 `ABORTED` 并停止发送。

动作完成后由飞手降落，再按：`A -> Q`。

## 5. `p`：位置偏移

只有 `n` 通过后才做。飞手先起飞并悬停，进入：`1 -> p -> M -> P`。

`P` 使用 DJI 水平位置控制，目标是相对当前位置沿地面 x 方向偏移约 `0.5 m`，垂直和转向保持 0。

预期飞机向目标方向移动，最多发送 5 秒后停止。当前程序没有位置反馈闭环，所以这里只验证方向和 API 是否工作，不承诺精确停在 0.5 m。飞手接管并降落，再按：`A -> Q`。

## 6. `t`：组合速度轨迹

只有 `n/p` 通过后才做。飞手先起飞并悬停，进入：`1 -> t -> M -> T`。

程序每段发送 1 秒，共 4 段：

```text
{0.2, 0.0, 0.0, 0}   # 前进
{0.2, 0.1, 0.0, 0}   # 前进 + 右移
{0.0, 0.1, 0.0, 10}  # 右移 + 右转
{0.0, 0.0, 0.0, 0}   # 停止
```

预期飞机按顺序执行四段动作。RC 夺权后应立即进入 `ABORTED`，轨迹停止。飞手接管并降落，再按：`A -> Q`。

## 每个运动程序都必须满足

```text
M -> ACTIVE
开始动作
RC 夺权 -> ABORTED，停止发送
U -> IDLE
A -> IDLE
```

若出现“已 `ABORTED` 但仍持续运动”、无法释放权限、无法退出，或出现连续通信错误：停止测试，保留完整日志，不要继续按其他动作键。
