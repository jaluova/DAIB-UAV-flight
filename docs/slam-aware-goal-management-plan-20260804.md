# SLAM 友好的目标管理与轨迹约束方案

日期：2026-08-04

状态：方案备忘，尚未实现。后续讨论和实现应以本文为起点。

## 1. 背景

当前 Foxglove/RViz 手动点击产生的 `map` 坐标目标会直接进入 EGO。EGO
主要优化位置轨迹，轨迹服务器再根据未来轨迹切线计算 yaw，二者没有形成
完整的视野与可观测性约束。

已经观察到的失效过程：

- 点击侧后方目标后，EGO 仍能生成位置上可行的轨迹；
- 无人机在平移的同时以受限 yaw 速度转向，形成较大的后退或 U 形转弯；
- 前视相机进入弱观测区域，FAST-LIVO 发生明显漂移或位姿跳变；
- 全局地图检测到 SLAM `pose jump` 后锁止，随后规划云可能断流；
- 当前 `0.35 rad/s` 的 yaw 限速完成 180 度转向约需 9 秒，单纯调高 yaw
  速度会进一步增加 SLAM 风险，不能解决根因。

## 2. 核心原则

手动点击点只表示最终意图，不能直接作为 EGO 的下一段局部目标：

```text
Foxglove 最终目标
        -> 目标管理器
        -> 原地转向或前向局部子目标
        -> EGO 局部平滑轨迹
        -> PX4/XTDrone 执行
```

全局目标可以位于任意方向或尚未观测区域；交给 EGO 的局部子目标必须位于
当前可观测、已知自由且具有足够净空的区域。

## 3. 目标状态机

建议增加轻量状态机：

1. `VALIDATE_GOAL`
   检查 frame、数据新鲜度、距离、高度、地图状态和目标有限性。
2. `YAW_ALIGN`
   当目标位于侧后方时保持当前位置，只缓慢调整 yaw。
3. `SELECT_SUBGOAL`
   在机头前方的已知自由空间采样并选择局部子目标。
4. `EXECUTE_LOCAL`
   将局部子目标交给 EGO，并持续检查跟踪误差与观测质量。
5. `HOVER_FAULT`
   SLAM、点云桥或局部地图异常时悬停，禁止继续生成新段。

只有 yaw 误差进入阈值后，才允许从 `YAW_ALIGN` 进入平移阶段。

## 4. 初始约束参数

第一版建议采用保守值：

| 参数 | 初始值 |
|---|---:|
| 前向候选视锥 | 正负 60 度 |
| 直接局部规划最大距离 | 3.0 m |
| 局部子目标典型距离 | 2.0-3.0 m |
| 允许开始平移的 yaw 误差 | 15 度 |
| 原地转向 yaw 速度 | 0.15-0.20 rad/s |
| 子目标最小障碍净空 | 0.6-0.8 m |
| 候选点数量 | 32-64 |
| 子目标选择频率 | 2-5 Hz |
| 未知区域 | 禁止作为局部子目标 |

参数需要通过 Indoor3 仿真数据重新标定，不能直接视为最终实机参数。

## 5. 子目标选择

候选点只从无人机前向视锥和现有局部体素地图中产生。硬约束包括：

- 位于局部地图有效范围内；
- 起点到候选点的射线穿过已知自由空间；
- 不在原始障碍或膨胀障碍内；
- 满足地板、天花板和墙体净空；
- 相对最终目标产生有效进展；
- 不要求立即进行大曲率或后向运动。

通过硬约束后再进行轻量评分：

```text
score =
    w_progress   * 朝最终目标的进展
  + w_clearance  * 障碍净空
  + w_observed   * 已观测区域比例
  - w_yaw        * 所需偏航变化
  - w_lateral    * 侧向/后向运动
  - w_curvature  * 轨迹曲率
  - w_slam_risk  * 弱观测风险
```

评分只查询现有 `0.25 m` 局部体素地图，不引入稠密全局 ESDF或大规模
优化。该部分应保持固定候选数和有界射线长度，适配香橙派 5 Max。

## 6. 轨迹与 yaw 协同

需要补齐的执行约束：

- 轨迹服务器从当前 PX4 odometry 初始化 yaw，不能固定从 `0 rad` 开始；
- 偏航未对齐时保持当前位置，不推进位置 B-spline 时间；
- 平移阶段惩罚机体系侧向速度和后向速度；
- 转弯时降低平移速度，并限制 yaw 加速度和轨迹曲率；
- yaw 朝向应优先服务于传感器可观测性，而不是只跟随远期位置切线；
- 跟踪误差持续增大时先悬停，不应无限重锚并继续运动。

## 7. SLAM 健康门控

第一版直接使用现有状态：

- `/daib_px4/planning_input_state == NORMAL`；
- `/daib_map/local/state == NORMAL`；
- 局部规划云持续更新；
- PX4 odometry 新鲜且有限。

后续可加入 FAST-LIVO 点数、特征数、位姿增量和观测几何评分。贴墙、快速
上升、连续旋转或有效点数下降时，应降低速度或进入悬停，而不是继续扩展
轨迹。

## 8. 地图职责

- `map` 局部地图负责实时避障和子目标可见性检查；
- `mission_map` 全局地图负责历史环境展示和最终目标方向参考；
- 长距离全局目标不能直接形成一条跨越未知区域的 EGO 轨迹；
- 全局地图发生 SLAM discontinuity 时继续锁止，不能通过关闭保护来掩盖
  坐标会话不一致。

## 9. 建议实现顺序

1. 为手动目标增加距离、前向视锥和已知自由空间过滤。
2. 增加 `YAW_ALIGN`，实现先原地转向、后平移。
3. 让轨迹服务器从 PX4 odometry 初始化当前 yaw。
4. 增加前向滚动子目标选择和固定规模候选评分。
5. 加入 SLAM 观测质量评分和自适应限速。

## 10. 验收标准

- 点击正后方目标时，无人机先原地转向，不产生后退大圆弧；
- 点击远处或未知区域时，EGO 每次只收到前方已知自由子目标；
- 转向期间位置漂移保持在设定阈值内；
- 目标执行期间没有持续的 tracking-error 重锚；
- FAST-LIVO 不因单次目标动作产生明显位姿跳变；
- 局部地图和规划云保持 `NORMAL`；
- 候选选择耗时有界，在目标平台上不影响 EGO 和 SLAM 更新频率。

## 11. 当前临时操作约束

在该方案实现前，手动点击只选择机头前方正负 45 度、距离 2-3 m 的点。
键盘控制必须在发送 EGO 目标前停止。出现 SLAM 位姿跳变后，需要重新建立
SLAM 会话，并依次重启点云桥、地图和 EGO，不能沿用已经漂移的全局地图。
